Binary Search Tree Rules

  • Values smaller than a node go to its left subtree.
  • Values greater than or equal to a node go to its right subtree.
  • Each subtree must also follow the BST rules.
  • Duplicate values are allowed and go to the right.
  • In-order traversal displays values in ascending order.
